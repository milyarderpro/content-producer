# Trivia fact checking, source policy and risk

## Current v2 research — sentence plus one URL

Open and assess one real page
supporting the entire atomic claim; one `source_url` is sufficient. The backend
validates URL shape/consistency, not source-page content. Do not fabricate sources
or treat a save timestamp as verification. Metadata such as tier, independence,
ontology, freshness class or expiry is not required. Use the same research path
for all Page topics; topic category alone does not impose a two-source quota.
General accuracy/safety still applies. AI answers, social/competitor text and
the example dataset are discovery leads, not independently verified evidence.

Research more candidates than the final Page fact count. Replace unsupported,
uncertain, used or incomplete-dedup candidates; research additional reserves when
needed. Keep negation, quantities, units and material qualifiers. If context
would exceed budget, choose a shorter accurate angle or another fact. No year is
mandatory on every fact. Do not reintroduce long academic phrasing as a gate.
Same-meaning canonical URL refresh uses maintenance request version 2;
draft-local URL updates use `revise_post_v2`. Material correction needs separate
explicit owner permission. Neither refresh rewrites published source snapshots.
See [core source policy](../../core/source-policy.md) and [dedup](dedup-ontology.md).
