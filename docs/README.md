# Developer documentation

The [phase tracker](../plans/implementation-plan.md#16-phase-tracker) records
current progress. The [local development runbook](runbooks/local-development.md)
describes the current local environment. Product and tool contracts remain
canonical in the frozen documents under `plans/`.
The `specified` rows in `plans/acceptance-traceability.md` are the frozen
requirement mapping, not the current implementation status.

Checkpoint reports and decision records document what was known or decided
when they were written. For the Phase 5 exit, read the
[final remediation verification](phase-5-batch-b-remediation-p2-03-report.md)
alongside the earlier [remediation handoff](phase-5-batch-b-remediation-report.md).
The handoff's pending-audit language is historical; it is not the live phase
status. The tracker states the closure basis and any evidence limitation.
