Ini snapshot diagnostik lintas format, **bukan** lima percobaan seversi yang homogen, uji kausal sebelum–sesudah, atau prediksi views.

Page tunggal: `Trivia Editorial Test (Internal)`, public ID `f3984ee4-8ae7-4043-8c93-45765f82f46e`. Tidak membuat Page lain. Pemilik hanya menyalin **satu prompt lengkap** yang reviewer berikan ke chat baru dengan plugin PRIVATE Content Producer, lalu meneruskan **seluruh jawaban akhir** AI penguji. Reviewer menilai dan menyimpan hasil; pemilik tidak mengedit file, memilih fakta, memberi skor, atau memberi GO editorial kedua.

## Batas operasi per kasus

- Prompt awal mengizinkan **satu** `trivia_register_and_reserve_facts` dan **satu** `save_post` pada Page di atas untuk satu draft uji, setelah riset, dedup, dan preflight bukti sesuai plugin. Ini bukan izin membuat Page, draft kedua, `revise_post`, `approve_post`, publikasi, atau perubahan config. Kontrol izin host tetap berlaku dan tidak dapat dilewati oleh prompt.
- Gunakan alur normal plugin dalam satu chat: context → riset → dedup → paket bukti terstruktur → reserve → compose/save → `get_post`. `content_payload.text_metrics: {}` dan renderer mengikuti kontrak plugin/server. Tidak ada checkpoint GO antarchat. Jika klaim/sumber tidak layak, berhenti aman; jangan memaksakan kuota. Jika Write ditolak pasti, jangan membuat payload baru atau draft kedua; laporkan kode dan `field_errors`. Jika respons hilang, rekonsiliasi Read dan hanya ikuti pemulihan same-key/same-payload yang sah. Reservasi yang dipastikan tidak dipakai dapat dilepaskan sesuai alur plugin; jangan release bila status save belum pasti.
- Plugin meneliti sumber; reviewer **tidak membuka atau mengaudit URL per fakta**. Jawaban akhir cukup memberi ringkasan kelayakan bukti, bukan daftar URL/favicons. Jangan tampilkan credential, operation key, reservation token, atau source text panjang.
- Nilai **copy pertama yang terlihat**. Bila tersimpan, pertahankan revision 1 tanpa revisi untuk menaikkan skor. Workflow `PASS` hanya jika `save_post` dan `get_post` cocok; skor DNA tidak mengubah verdict tool. Draft dengan checks gagal atau `quality_status: pending` tetap draft, bukan `ready`.
