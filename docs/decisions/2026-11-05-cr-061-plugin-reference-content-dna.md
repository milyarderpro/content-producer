# CR-061 — DNA referensi sebagai kewajiban penulisan plugin

Status: Accepted. Tanggal keputusan awal: 5 November 2026.
Ringkasan source publik; trace evaluasi dan metadata QA privat disimpan terpisah.

Pemilik mengarahkan seluruh copy pada pola Curious Mind, DYK, dan Daily Facts:
topik familiar, ragam kejutan, urutan perhatian dan en-US nonakademik bagi
US/UK/CA/AU. Dataset adalah referensi pola, bukan bukti kebenaran fakta.

Keputusan ini menyempurnakan saran editorial pada DNA frozen dan CR-053;
kontrak server tidak diubah. Review angle, variasi, naturalness, qualifier dan
budget wajib sebelum preview/save/revise. Setelah dua repair terarah gagal,
laporkan keterbatasan tanpa menyimpan filler. Default hook Did you know?;
7–8 fast/5–6 utility adalah preferensi, count/config eksplisit dan budget tetap
mengendalikan. Jumlah draft tidak menentukan jumlah fakta.

Comparison membutuhkan kontras nyata yang layak diceritakan. Dimensi antarbaris
boleh berbeda; perbandingan metrik tetap setara scope/unit/waktu. Dua subjek
tidak wajib di setiap baris. Myth correction mengoreksi klaim langsung.
Pengulangan dinilai dari pengalaman pembaca, termasuk care/komunikasi/penjagaan.
Timeline gagal–diperbaiki–dipakai tetap kronologi walau tanggal dihapus.

Addendum 6 November 2026, remediasi Issue #134–#136 yang diotorisasi pemilik:
periksa scope/populasi/approximation pada setiap kalimat final; kurasi set
pilihan agar preferred count tidak mengundang filler; nama objek asing diberi
penjelasan; format plan boleh null saat belum dipilih dan harus mengikuti
perangkat editorial, bukan bobot. Intent eksplisit tetap dihormati. Revisi post
yang diotorisasi dapat memperbaiki format tanpa menulis ulang plan completed.

Tidak menambah enum/backend gate, mengubah OAuth/RLS, dedup/CAS, tiga
attestations v2 atau approval owner. Source/CI/package, penerimaan editorial,
dan bukti saved-copy LIVE dipisahkan. Skor tinggi, instalasi dan HTTP 200 bukan
bukti FIXED; retest relevan harus membuktikan copy, revision/hash dan checks.
